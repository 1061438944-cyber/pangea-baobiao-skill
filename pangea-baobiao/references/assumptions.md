# 不是读自 Figma 的值

下面这些值是站点在 Figma 缺数据时补上的，或者是对 Figma 图形的近似。使用时如实说明，不要当作正式规范。

## 通用补充

- 分页当前页、时间选择器选中项：primary-1 背景 + primary-6 文字（Figma 未读到非禁用的选中样式）。
- 代码编辑器字号 13 / 20。
- 水印的文字、间距、角度为示例值。
- Statistic 趋势箭头与数值同色。
- 抽屉宽度 440 / 640px 为示例。
- 信息提示图标 #165DFF 取自组件实际颜色，令牌中只有 info-1 / info-6。
- 未还原：Switch 滑块图标与滑轨文字、DatePicker 的月 / 年 / 周 / 季度 / 时间面板、卡片式页签。

## 各组件页面上的说明

- **Button 按钮**：虚框按钮在 Figma 中的虚线为 4 / 4，网页用 CSS dashed 近似。令牌名按色值与 Figma 颜色变量匹配；同一色值对应多个令牌时，按背景、边框、文字的用途取对应分组。
- **Link 链接**：Figma 中链接图标使用 12px 的 icon-wrapper，没有指定具体图标；示例用 Pangea 图标 link。
- **Statistic 数值显示**：Figma 中趋势箭头没有单独设置颜色；在报表中表达涨跌时，按颜色页的涨跌语义色上色。
- **Table 表格**：分页“选中”状态在已读取的变体里只有禁用样式，这里用 primary-1 底色和 primary-6 文字表示当前页。
- **CodeEditor 代码编辑器**：代码字体与行高在 Figma 中未单独标注，示例使用等宽字体 13 / 20。
- **DatePicker 日期选择器**：Figma 中面板还有月、年、周、季度、带时间和预设范围几种类型，本页先还原最常用的日期与范围选择。
- **Switch 开关**：Figma 中还有“滑块图标”和“滑轨内容（图标 / 文字）”两种变体，本页暂未还原。
- **TimePicker 时间选择器**：Figma 中未给出时间项的选中样式，这里用 primary-1 底和 primary-6 文字表示选中。
- **Alert 警告提示**：信息色只读到了 info-1（#E8F3FF）这个令牌，图标的 #165DFF 来自 Figma 组件中实际使用的色值。
- **Watermark 水印**：Figma 的 Watermark 页面给的是整页示例，没有单独标注水印的字号、透明度和间距，这里的取值为示例。
- **Approval 流程审批专用**：流程图页签在 Figma 中只是“流程图嵌入区域”占位，这里画的节点图是示例，实际由流程引擎渲染。
- **FilePreview 预览容器**：顶栏为海信企业 logo 原图（126 × 20），不要改色、拉伸或用文字代替；纸面里的月报内容是示例。
- **UserPicker 人员选择器**：Figma 里头像是照片，这里用姓氏首字代替；人员和部门是示例数据。组织架构左侧在 Figma 中是带连接线的树，这里简化为缩进列表。
- **SliderVerify 滑动验证**：Figma 中图片区是一张照片，这里用矢量风景图代替；缺口位置每次随机生成。
