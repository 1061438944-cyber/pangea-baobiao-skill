# 会议大屏与来源差异

本文件沿用旧版 pangea-ui Skill 的第八至十节（2026-10-29 整理，来源 Figma 文件 KqNpaABKE6k6o3kK3SVeLs 中财务、制造、供应链三类经营分析大屏样本）。这些是**样本观察值**，不是全局规范；与《集团报表规范》冲突时按 SKILL.md 第三节处理。

## 八、经营分析大屏规范

本节基于财务、制造、供应链三类样本。

### 画布与布局

观察到的设计基准：1920 × 1080。

同系列延展时优先延续：
- 顶部主导航。
- 第二层业务页签。
- 内容区域的模块化卡片。
- 页面左右边距 32。
- 常见卡片间距 16。
- 三等分布局的卡片宽 608。

这些是样本参数，不是通用中后台断点规范。
其他尺寸根据目标展示环境重新安排，不能简单缩小文字。

### 背景与卡片

样本页面背景：#F3F3F5。

主要卡片：
- 白色背景。
- 圆角 12。
- 内边距 16。
- 阴影：X 0、Y 4、模糊 14、扩展 0、黑色 6%。

此阴影与通用 shadow 样式不同。
修改同系列大屏时保留其局部规则。

### 信息组织

常见卡片结构：
1. 指标标题与单位。
2. 当月/累计切换，或其他适用维度。
3. 浅青色指标摘要带。
4. 实际、计划、完成率、同比等辅助指标。
5. 趋势图。
6. 必要的业务点评或异常说明。

可采用：
- 顶部三张指标卡 + 下方明细表。
- 上方三列 + 下方不等宽组合。
- 按成本、交付、资金等业务维度纵向分区。

依据业务关系选择组合，不机械复制所有模块。

### 图表颜色

财务样本中的系列映射：
- 计划：#FF4F31。
- 实际：#00BBB3。
- 同期：#ECB500。

其他观察到的辅助色：
- #3491FA：部分比较值和强调信息。
- #5082F9：部分额外图表系列。

上述颜色为业务设计观察，不是新增全局变量。

扩展图表时：
- 先核对原图例和系列映射。
- 同一指标在跨页、跨图中保持一致。
- 不自动将红色系列解释为异常。
- 不自动将蓝色解释为改善。
- 超出已有系列时再补充可区分颜色，并说明是新增。

### 数据表达

必须保留：
- 指标名称。
- 统计时间。
- 单位与口径。
- 当月、累计、计划、实际、同期的区别。
- 同比、环比、完成率和改善值的区别。

不得：
- 将百分比变化与百分点混写。
- 因数值上升就判断为利好。
- 将缺失数据填成 0。
- 复制样本占位文字为最终业务内容。
- 擅自修正用户提供的异常数值。

成本、费用、周期等指标可能越低越好。
异常语义需按指标目标和业务定义判断。

有来源的原始数据优先。
仅在用户允许时生成示例数据，并明确标识。

## 九、间距、圆角与阴影的边界

当前仅发现 Colors 变量集合：
- 200 个本地颜色变量。
- 单一 Mode 1。
- 未发现间距、尺寸、圆角类本地变量。
- 未发现独立深色主题模式。

不得把观察值命名成已经存在的全局令牌。

通用效果样式：
- shadow/shadow-1：0 / 2 / 5 / 0，黑色 10%。
- shadow/shadow-2：0 / 4 / 10 / 0，黑色 10%。
- shadow/shadow-3：0 / 8 / 20 / 0，黑色 10%。
- shadow/BackTop：0 / 4 / 10 / 0，黑色 10%。

已有组件样式优先于概括性套用。

## 十、已知来源差异

基础规范中存在：
- primary-1 文字标注与实际样式不一致；
  已读取样式及变量为 #E8FFFB。
- color-fill-5 文字标注与实际样式不一致；
  已读取样式及变量为 #4E5969。
- 部分功能色说明区复用了中性色标注。
- 部分颜色样式与变量名称存在空格差异。
- 部分样式绑定目标不在已读取本地变量列表内。
- warning-10、orange-10 的源值为 #4D000A。

遇到冲突：
1. 读取当前组件和实际绑定。
2. 区分说明标注与真实资产值。
3. 说明采用值及原因。
4. 不擅自修改源规范或重新绑定全库。
